# 퇴직 설계 — 콘텐츠

[퇴직 설계](https://play.google.com/store) 앱이 실행할 때 읽어 가는 콘텐츠 파일입니다.

앱에는 같은 파일이 처음부터 들어 있어 **인터넷 없이도 동작합니다.** 이 저장소의 파일은
제도가 바뀌었을 때 스토어 심사 없이 내용을 고치기 위한 것입니다. 앱은 실행할 때
여기 `version` 을 확인하고, 더 높으면 받아서 교체합니다. 받지 못해도 앱은 그대로 동작합니다.

```
https://raw.githubusercontent.com/pallak83-tech/retirement-content/main/content.json
```

## 이 파일을 직접 고치지 마세요

`content.json` 은 생성물입니다. 원본은 앱 저장소의 `content-src/` 에 있고,
`tools/build_content.py` 가 출처와 스키마를 검사한 뒤 이 파일을 만듭니다.
출처(기관·연도)가 없는 항목은 빌드가 거부합니다.

여기 파일만 고치면 다음 갱신 때 덮어써집니다.

올리는 것도 손으로 하지 않습니다. 앱 저장소에서 `python tools/publish_content.py` 를
실행하면 빌드·출처 검사·올리기·확인까지 한 번에 합니다. 이 README 의 개수 표도
그때 실제 파일에 맞춰 다시 씁니다.
